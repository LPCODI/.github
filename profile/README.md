AI Speech

## 프로젝트 소개

AI Speech는 대학 프로젝트 발표를 준비하는 사용자를 위한 AI 기반 발표 연습 도우미입니다.

사용자가 PPT, PDF, DOCX 형식의 발표 자료를 업로드하고 전체 발표 시간과 질의응답 시간을 입력하면, AI가 발표 자료를 분석해 슬라이드별 발표 시간을 배분하고 교수님 앞 발표에 적합한 발표 대본을 생성합니다.

발표자는 스마트폰을 앞에 두고 실제 발표처럼 연습할 수 있으며, 시스템은 음성, 자세, 시선, 반복 행동을 분석해 발표 개선 방향을 제공합니다.

## 문제 정의

대학 프로젝트 발표에서는 발표 자료와 대본을 준비해도 실제 발표 과정에서 여러 문제가 발생할 수 있습니다.

- 제한 시간을 초과하거나 너무 빨리 끝나는 문제
- 특정 슬라이드에 시간을 과도하게 사용하는 문제
- 슬라이드 내용을 그대로 읽는 발표 방식
- 핵심보다 부가 설명이 길어지는 문제
- "어", "음", "그니까" 같은 추임새 반복
- 말하기 속도, 자세, 시선 처리 문제
- 교수님의 예상 질문에 제대로 답변하지 못하는 문제
- 자신의 발표를 객관적으로 평가하기 어려운 문제

AI Speech는 발표 자료 분석, 시간 배분, 대본 생성, 발표 리허설, 음성 및 영상 분석, 교수 관점 평가, 질의응답 훈련을 하나의 흐름으로 제공합니다.

## 주요 기능

### 발표 자료 분석

업로드된 발표 자료에서 슬라이드 제목, 본문 내용, 핵심 키워드, 표와 그래프, 이미지, 슬라이드 간 연결 관계를 분석합니다.

분석 결과를 바탕으로 각 슬라이드의 핵심 메시지와 교수님이 질문할 가능성이 높은 지점을 도출합니다.

### 슬라이드별 시간 자동 배분

전체 발표 시간과 질의응답 시간을 기준으로 실제 발표 가능 시간을 계산하고, 슬라이드의 중요도와 설명 난이도에 따라 시간을 자동으로 배분합니다.

시간 배분 기준은 다음과 같습니다.

- 슬라이드 중요도
- 텍스트 분량
- 표와 그래프의 복잡도
- 프로젝트 핵심 기능 포함 여부
- 시스템 구조 설명 여부
- 기술 선택 이유
- 구현 결과 및 한계 설명

### 교수님 발표용 대본 생성

교수님 앞 대학 프로젝트 발표에 적합한 발표 대본을 생성합니다.

대본은 슬라이드 내용을 그대로 읽는 방식이 아니라, 핵심 메시지와 보충 설명을 포함해 발표자가 자연스럽게 설명할 수 있도록 구성됩니다.

### 음성 분석

스마트폰으로 발표한 음성을 분석해 발표 습관을 확인합니다.

- 실제 발표 시간
- 슬라이드별 소요 시간
- 계획 시간과 실제 시간의 차이
- 평균 말하기 속도
- 추임새 횟수
- 긴 침묵
- 반복 표현
- 대본에서 누락한 내용
- 불필요하게 추가된 설명

### 자세 및 시선 분석

스마트폰 카메라를 활용해 발표자의 자세와 시선을 분석합니다.

- 몸을 반복해서 흔드는 행동
- 고개를 숙이는 행동
- 구부정한 자세
- 과도한 손동작
- 발표 화면만 보는 시선
- 바닥을 보는 시선
- 교수님 또는 카메라 응시 비율

단순히 한 번 발생한 행동으로 평가하지 않고, 반복 횟수와 지속 시간, 발생 구간을 함께 분석합니다.

### 다중 AI 에이전트 평가

AI Speech는 발표를 세 가지 관점에서 평가합니다.

- 교수 에이전트: 문제 정의, 목표, 기술 선택 이유, 구현 가능성, 차별성 평가
- 학생 에이전트: 발표 이해도, 흐름, 설명 난이도, 집중도 평가
- 최종 판단 에이전트: 음성, 자세, 시선, 질의응답 결과를 종합해 개선 우선순위 제시

### 실전 질의응답 시뮬레이션

발표 자료와 대본을 기반으로 교수님이 질문할 가능성이 높은 예상 질문을 생성합니다.

예상 질문 예시는 다음과 같습니다.

- 이 기술을 선택한 이유는 무엇인가요?
- 기존 서비스와의 차별점은 무엇인가요?
- 실제 구현 가능성은 어떻게 검증하나요?
- 사용자 데이터는 어떻게 보호하나요?
- 프로젝트의 한계와 개선 방향은 무엇인가요?

사용자의 답변은 논리성, 구체성, 기술적 정확성, 질문 의도 이해 여부를 기준으로 분석됩니다.
